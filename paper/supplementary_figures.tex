\section*{Overview}
This Supplemental Material accompanies the main PRB article on coupled $(\epsilon,\delta)$ response in qHP C$_{60}$.
All figures and tables are labeled with prefix~\textbf{S} to match citations in the main text (Fig.~S4--S6; Tables~S1--S5).
Calculations use the same PBE+DFT-D3 CP2K protocol as the main manuscript (rigid biaxial strain unless noted).
Observables follow Capobianco \emph{et al.}~\cite{Capobianco2024electron}: $\pi$-projected DOS, inverse participation ratio (IPR), nearest-neighbor coupling $J$, and Marcus reorganization energies $\lambda^{\pm}$.
Converged inputs, outputs, and analysis JSON are archived as described in the main-text Data Availability statement.
